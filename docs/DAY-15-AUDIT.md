## Security and evidence limits

Wallet ownership and exact transaction calldata are authoritative. Quotes bind chain, owner, source catalog and declaration hashes, five-minute expiry and exact amount; each action rechecks current eligibility. Requests are unpriced; estimated shares are not guaranteed or protected by an async minimum-share parameter. Explicit approval does not override issuer restrictions. Token approvals are exact and reset previous allowances; abandoned instructions can leave allowance and require wallet revocation. Model output source IDs are validated, but a cited paragraph still needs semantic verification against its source.

Actual local-chain tests deploy test-only USDC, issuer/share and aggregator contracts and execute real wallet-signed USDC flows against them. Jev is an explicit HTTP double. These are not production issuer or Chainlink proofs. The separate Base mainnet asset/share/NAV reads succeeded without signing or broadcasting. Real issuer onboarding, reviewed country/minimum/terms catalog, actual testnet/mainnet vaults/feeds, paid model calls, Supabase persistence, independent wallet acceptance and hosted release remain unchecked in the completion tracker.

The app has no public investor multi-tenancy, background issuer monitoring, automatic document refresh or offchain KYC service. Issuer cancellation/recovery and specialized instant exits are direct protocol workflows, not fabricated concierge actions. Catalogs support up to twelve products, with explicit quote/conversation archive limits; export/rotation and retention need a production process. No custom production contract was deployed or is required by this adapter.
