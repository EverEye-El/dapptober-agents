## Authority, privacy and remaining work

Public tools are bounded read/compute/reasoning operations; they cannot invoke arbitrary contracts or transfer funds. The vault enforces authority independently of Jev. Published blueprints are immutable; fork to change them. Owner service pause and onchain financial pause are separate actions. Exact pending transactions are preserved/reconciled rather than silently replaced. Publishing can retry the same immutable record without resetting its usage after a partial response/storage failure.

TypeSafe receives approved metadata only; live `text.brief` requires separate caller consent before raw text reaches OpenAI. Server seed/provider keys are not exposed. Demo never invents registry IDs, deployment evidence, paid-model calls or money movement. Counterfactual executor provisioning does not prove a deployed smart account. The public MCP profile is a service inside this hosted app; manifest export does not automatically create a separate cloud deployment.
