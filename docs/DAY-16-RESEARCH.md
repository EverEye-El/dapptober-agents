## Engineering choices

Base Sepolia 84532 testing, Base 8453 production. No testnet switch. One independent Day 16 app can host three separately credentialed seller actors; external reviewed seller services are supported via exact HTTPS endpoint/card configuration. Agent discovery is administrator-curated plus cards/registry, not an untrusted open URL input or full market-wide registry crawler.

Buyer deterministically negotiates inside a mandate and seller uses typed Jev decisions. Humans authorize funding and release; no unattended buyer signer. Contract hard cap and exact signed terms contain financial behavior. Seller signs delivery hash; buyer reviews quality. Escrow has full missed-delivery refund, 24-hour review, immutable arbiter and 7-day unresolved-dispute 50/50 fallback. These terms are explicit before payment; no algorithm pretends to prove subjective work quality.

All settlement methods remain available directly onchain if app is unavailable. Operator must monitor review/timeout windows. No funds can be withdrawn by administrator outside the defined resolution paths. No public-chain transaction or live model result was generated during research.
